# Alkami

> Alkami Technology (NASDAQ: ALKT) is a cloud-based digital banking platform for U.S. banks and credit unions. Its "Alkami Foundry" developer program exposes RESTful APIs and an extensible SDK — covering authentication, money movement, data access, and real-time/batch workflows — that financial institutions and fintech partners use to embed and extend digital-banking experiences. The APIs are built on OpenID Connect. Developer documentation, API reference, and credentials are delivered through the gated Alkami DevPortal.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public Alkami surface and the artifacts in this repository. Alkami does not publish a public OpenAPI specification or open developer documentation; the technical reference lives behind DevPortal authentication.
